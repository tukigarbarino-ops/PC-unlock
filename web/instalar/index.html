Instalar en la ESP32

Versión …

1 Conectá la ESP

  1. Abrí esta página en la compu con Chrome o Edge.
  2. Enchufá la ESP32 con un cable USB que pase datos.
  3. Si al tocar Instalar no aparece ningún puerto, instalá el driver del chip USB de tu placa (CP210x o CH340).

2 Instalá

Elegí el puerto (COM…) y confirmá. Si se queda en “Connecting…”, mantené apretado el botón BOOT de la placa hasta que empiece.

Este navegador no puede conectarse a la ESP. Usá Chrome o Edge en la compu.

Hace falta abrir la página por HTTPS.

3 Configurá desde el celu

  1. En la app, en Configuración, copiá el código para la ESP.
  2. En el iPhone: Ajustes → WiFi → PC-Unlock-XXXX (clave pcunlock).
  3. Se abre la página de la ESP (si no, entrá a http://192.168.4.1). Pegá el código y cargá tu WiFi, la MAC y el PIN.
  4. En Windows: Configuración → Bluetooth → Agregar dispositivo → PC Unlock.

Para volver a este modo más adelante: mantené apretado BOOT 3 segundos con la ESP andando.
