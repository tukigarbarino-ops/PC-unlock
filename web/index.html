1 Servidor MQTT

Los datos de tu cluster de EMQX (Access Control → Authentication).

2 Llave con Face ID

Crea una passkey en este iPhone. Solo se puede usar pasando Face ID, y con ella se firma cada orden.

3 Código para la ESP

Copialo, conectate al WiFi PC-Unlock-XXXX (clave pcunlock) y pegalo en la página que se abre.

4 Compu (pantalla remota)

Instalá PC Unlock Host en la compu y pegale el código del paso 3. Después compará el código de verificación.

5 ESP (teclado y mouse de respaldo)

Si el programa de la compu no está (compu bloqueada, recién prendida o colgado), el teclado, el touchpad y la multimedia van por la ESP como teclado/mouse Bluetooth, cifrados. Necesita la ESP con la versión 1.3.0.

Comparalo con el de la página de configuración de la ESP (BOOT 3 s → WiFi PC-Unlock-XXXX → “Código de verificación de esta ESP”).
